## P2 资源写入计数

对 `IDBObjectStore.put` 的 resources 写入计数，使用可确定大小的 source/mask 字符串夹具（测试存储，不代表有效图像解码）。初次保存确实写2份资源，共5164个字符串字符；随后一次重命名和一次图纸cells编辑，资源写入均为0，共0个资源载荷字符。旧的每次无条件写 source/mask 策略在相同两次更新中预期写4份、共10328字符；该旧策略数量由既有实现推导，未单独运行旧版本计时。字符数是载荷长度估算，不是物理磁盘字节或传输耗时，也不涉及哈希。

只更改mask时实际新增1次资源写入，复制到独立项目时新增2次；读取确认原项目新mask和副本原mask互不影响。此优化仍需读取资源并直接比较字符串，不能据此宣称图片读取/序列化成本归零。此次新增两项测试定向运行8项全部通过，无需重复全套已通过检查。

## 固定实验协议

使用公开 18 输入：原有 3 张 NASA/CC0 照片、9 张原创合成图，及本轮新增 6 张授权真实照片；另有用户角色图的私有回归。新增6张中5张灰度、1张彩色，仍缺授权彩色插画，不能声称类别均衡。公开来源见 [素材说明](../examples/dataset/SOURCES.md)。

固定 source、有效 mask、crop、64 格宽、K16、mean、当前 220 色卡。协议在运行前写入 ignored 的 `experiments/generated/constraints-protocol.json`。开发集为 astronaut 与奇数合成图；留出为 chelsea、coffee、偶数合成图及全部6张新增照片。新增照片的 ROI 全部预设源图中央 `[.25,.25,.75,.75]`，未依据结果移动区域。参数仍为 ROI 权重 3；必选一个源图 ROI 平均色的最近参考色。新增素材没有参数搜索。旧素材已有基线结果，因此旧样本不是全新独立盲评；用户图属于既有私有回归。

比较默认、同选择器全图 ROI/权重1控制、仅必选、仅 ROI、组合。控制用于排除选择器初始化差异；本批输入控制与默认结果一致。ROI 默认是按样例预定义的源图规范化矩形，与主体 box 分开；真实交互可另选。本实验不比较分割或缩采样改动。

## 真实 SAM 多图生命周期

复用已有 SAM2.1 Hiera Tiny 权重（156008466 字节，仅记录目录属性大小，未计算哈希）及已有 SAM2 源码；没有下载模型。`tests/check_real_sam.py` 为独立按需检查，不放入默认单元测试循环。通过环境变量 `SAM2_CHECKPOINT`、`SAM2_SOURCE` 指定现有安装位置。

实际用正式 backend 的 upload/segment 函数处理公开 cat A（256×170）和 coffee B（256×171），执行 A→A→B→A。初次按环境自动选 cuda 已通过；随后明确走真实模型 CPU 加载分支再次完成，用4线程。CPU检查只暂时覆盖设备可用性选择，模型、权重、predictor及推理均真实，未使用替身。私有 JSON 保留最后这次 CPU 结果。

|顺序|前景像素|encode ms|segment ms|总 ms|
|---|---:|---:|---:|---:|
|首次 A|7318|991.23|45.09|1037.23|
|缓存 A|7318|0|23.48|24.39|
|切换 B|9173|879.16|23.31|903.26|
|返回 A|7318|885.63|25.47|912.06|

四次 imageId/revision 与请求一致；每次掩码尺寸匹配、前景非空；缓存A不编码，B和返回A均重新编码。直接数组断言确认首次A=缓存A=返回A，没有哈希或指纹。此证据为真实模型和正式函数生命周期，未验证HTTP传输、浏览器框选或人体/所有物品分割质量；本机CPU仍不代表轻薄本实机。
