# 使用手册
1. 导入JPG/PNG，选择整图，或框选主体并补选/去除。
2. 掩码不准确时选择补回画笔/擦除选区；撤销修补恢复上一状态。
3. 生成并选择方案。自定义保持同规格比较平滑和色块；生成期间可以取消。
4. 在编辑图纸中缩放、移动、连续画笔、吸色；高亮仅影响显示。撤销按笔画生效。
5. 替换颜色前先预览；锁色保护合并和整色替换，不限制主动笔画。
6. 项目入口支持新建、命名、复制、回收站与恢复；当前项目不能移入回收站，先切换到其他项目。
7. 保存JSON备份，下载PNG、材料CSV或打印分块。打印对话框可保存PDF，按格制作，不宣称物理比例精确。
草稿随浏览器来源隔离。存储失败时先下载JSON。不要将包含私图的JSON公开提交。

## 本轮操作
导入项目默认新增独立作品。下载项目是可携带JSON备份，本地自动保存状态在顶部；失败时先下载备份。复制会先保存最新内容。切换/重命名不会把副本自动设为活动作品。

网格工具选择“选区”拖矩形，再展开替换颜色将范围切到“选区”，核对影响格数再应用。若增加新色超过K，请选择已用色或重新明确生成预算。源色锁定时先解锁。一次应用一次撤销。

自定义的“细节保护（实验）”可选≤4个候选必选色；它们计入K，可能零用量。ROI左/上/右/下为整张源图0–1坐标，设定后紫色框提示范围；点击应用/设区才提交，错误输入不影响项目保存。ROI方案不保证改善，默认方案保留。

打印默认黑白数字符号，×为空格，数字对应图例色号，白豆有数字。总览页加每块一页。实体钉距/打印缩放需核对，不能直接按屏幕尺寸下料。
