# 使用手册
1. 导入JPG/PNG，选择整图，或框选主体并补选/去除。
2. 掩码不准确时选择补回画笔/擦除选区；撤销修补恢复上一状态。
3. 生成并选择方案。自定义保持同规格比较平滑和色块；生成期间可以取消。
4. 在编辑图纸中缩放、移动、连续画笔、吸色；高亮仅影响显示。撤销按笔画生效。
5. 替换颜色前先预览；锁色保护合并和整色替换，不限制主动笔画。
6. 项目入口支持新建、命名、复制、回收站与恢复；当前项目不能移入回收站，先切换到其他项目。
7. 保存JSON备份，下载PNG、材料CSV或打印分块。打印对话框可保存PDF，按格制作，不宣称物理比例精确。
草稿随浏览器来源隔离。存储失败时先下载JSON。不要将包含私图的JSON公开提交。
