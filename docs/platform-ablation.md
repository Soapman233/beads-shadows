# 细节保护、交换优化与库存限色

执行 `frontend/node_modules/.bin/tsx.cmd experiments/run-platform-ablation.ts`。复用 6 幅公开或自制样例的工作图和掩码。各组固定 64 格宽、mean 采样与 16 色上限，逐格检查掩码一致。ROI 为归一化中心 [0.25, 0.25, 0.75, 0.75]，权重 3，必选色为空。库存组使用 MARD220 顺序中的偶数索引 110 色，作为可复现的示例库存。指标是全图有效格 CIEDE2000 均值。

|样例|基准|ROI|单色交换|库存限色|
|---|---:|---:|---:|---:|
|astronaut|6.572|6.748|6.559|7.951|
|chelsea|6.969|6.969|6.969|9.107|
|coffee|5.728|5.742|5.728|7.640|
|synthetic-3|2.106|2.106|2.106|7.395|
|synthetic-4|3.630|3.630|3.630|4.947|
|synthetic-9|6.665|6.665|6.665|8.182|

交换优化在一幅图略微降低误差。ROI 的收益需查看局部指标，全图误差在两幅样例上增加。库存约束把结果限制到可选物料色号，六幅图的均值均上升。示例库存只描述色号可用性，数量足够与否仍需材料清单逐项检查。

本机 Intel Core Ultra 7 265K 同机 8 并发完成 40 次目录读取，40 次 HTTP 成功，中位 19.4 ms、P95 126.7 ms。请求在数据库色卡列表和公开作品列表间交替。此数据记录的是合成低并发读路径。轻薄本、协作压力和实际学校部署需要另行测量。
