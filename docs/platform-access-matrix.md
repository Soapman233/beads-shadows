# 多用户权限与外部服务验收矩阵

## 角色和资源边界

本表从服务端实际路由和页面整理正常业务权限。本人指有效会话对应的资源所有者。其他账号指没有获得对应资源授权的普通用户。协作者按房间的只读或编辑授权访问图纸。管理员使用管理入口，对其他账号的源图和完整私有项目仍需满足普通所有权检查。关闭且尚未恢复的账号没有有效会话，匿名公开入口仍可访问。

| 资源与入口 | 游客 | 本人 | 其他账号 | 协作者 | 管理员 | 已关闭账号 |
|---|---|---|---|---|---|---|
| 登录与个人资料 `/auth/*` | 可注册和登录 | 可读写本人资料、改密、退出 | 各自资料 | 同普通账号 | 可查目录和处理账号状态 | 登录与找回需符合账号状态和恢复流程 |
| 临时图像 `/images`、`/segment` | 访客作用域内可上传和分割 | 本人作用域内可上传和分割 | 本人 ID 查询不到对方缓存 | 同普通账号，房间授权不延伸到原图 | 同普通账号 | 旧账号作用域失效，可使用游客作用域 |
| 源图、掩码和成品 `/assets*` | 无 | 本人可上传和读取 | 无 | 房间不包含这些资产 | 对他人私有图片无通用读权限 | 保管，旧会话不可读取 |
| 私有项目、图纸版本和回收站 `/projects*` | 本机游客项目与 JSON | 目录、版本、新建、修改、历史恢复、回收与找回 | 无 | 使用协作入口，项目私有版本不随房间授权 | 对他人私有项目无通用读权限 | 保管 |
| 账号导出和关闭 `/account/*` | 邮件可用时可请求找回、重置密码或请求关闭账号恢复 | 下载本人项目、版本、私有 PNG，普通用户可确认关闭本人账号 | 无 | 同普通账号 | 具备邮件验证码及操作理由时恢复关闭账号，可预览超期账户数 | 无有效会话。预先验证邮箱且仍在恢复时限内，可请求一次性恢复验证码 |
| 色卡 `/palettes*`、`/admin/palettes*` | 浏览已发布目录与已发布、退役版本 | 同游客 | 同游客 | 同游客 | 管理草稿、来源、版本资料、发布与退役 | 可匿名读公开版本 |
| 材料、库存流水和缺料 `/inventory*`、`/projects/{id}/versions/{revision}/materials` | 无 | 查看本人库存、入库、出库、导入，按本人的图纸核对用量 | 无 | 使用本人库存 | 无全局私有库存读入口 | 保管 |
| 制作记录、分块与成品 `/builds*` | 无 | 建立本人版本的制作记录，读写进度和成品档案 | 无 | 仅分享房间，不分享制作进度 | 无通用私有制作记录入口 | 保管 |
| 已公开作品 `/publications*` | 检索、PNG 预览，作者允许时下载 JSON | 同游客，另可收藏、举报、提交本人作品和撤回 | 同已登录读写范围，不能替对方发布或撤回 | 房间授权不授予发布权 | 审核、上下架及处理举报 | 关闭事务撤回待审和公开作品，仍能匿名浏览其他公开作品 |
| 合规二创 `/publications/{id}/remix` | 无 | 仅作者开放二创的已公开版本可复制，复制留溯源 | 同普通账号 | 同普通账号 | 同普通账号 | 无旧账户操作权限 |
| 评论、通知、私信 `/publications/{id}/comments`、`/messages*`、`/notifications*` | 可读已公开作品评论 | 本人通知、参与人私信、评论或举报 | 无权读对方私信及通知 | 同普通账号 | 可处理举报并按规则删除评论，审核接口只显示被举报内容 | 无旧账户操作权限，受保护历史留档 |
| 实时协作 `/collab/*`、`/api/collab/ws/{id}` | 无 | 项目所有者可邀请、撤销、提交新版本或使用结构租约 | 无 | 只读成员可查看房间。编辑成员可改格、撤销自己未被覆盖的操作、另存房间图纸 | 仅作为所有者或已授权成员访问具体项目 | 旧会话失效。关闭的所有者项目暂停房间访问，现有房间和操作历史留档 |
| AI 任务与额度 `/ai/*` | 平台模式可查能力。单机兼容模式受本机配置和明确同意控制 | 仅本人任务、额度、原图与输出，可取消或另存采用 | 无 | 房间授权不延伸到 AI 任务 | 发放额度、核对未知任务，看不到私有原图和结果 | 旧会话不可访问，关闭或冻结期间排队任务不向供应商发起 |
| 模拟商城 `/shop/*`、`/admin/shop/*` | 可查看能力标志、当前销售商品和会员计划 | 本人购物车、订单、会员和本地模拟操作 | 订单所有权隔离 | 同普通账号 | 管理模拟 SKU、订单、发货、退款和会员 | 不可凭失效会话操作，订单和库存流水留档 |
| 后台概况、审计和运维 | 无 | 无 | 无 | 无 | 管理 API 与业务审计。备份/资产维护由独立运维命令执行 | 无 |

读取校验采用 `auth.py` 的会话、账号状态与资源查询。带有 `X-Bead-Account` 的旧标签页在 Cookie 账号变化后会收到 401 或 409。跨账户的项目、资产和订单查询按所有者过滤，通常返回 404。管理员入口由 `require_admin` 检查。已登录的写操作校验会话 CSRF 令牌及合法来源。协作 WebSocket 另行检查会话、发起页面来源和成员关系，并在连接期间重新核对权限。

这些约束对应 `projects.py` 的 `find_project`、`find_asset`，`builds.py` 的 `find_build`，`publications.py` 的 `visible_publication`、`find_publication`，`collab.py` 的 `project_access`、`owner_room` 和 `socket_state`，以及 `commerce.py` 的 `find_order`。页面隐藏入口用于提示，后端查询负责授权。公开详情只返回预览地址和统计，精确格子由授权下载、二创或审核入口读取。

## 离线与缓存核对

- 首页在线优先。Service Worker 以构建静态清单预缓存应用壳，抓取静态文件时省略 Cookie。私有 API、直达资源路由、登录响应及个人原图不在清单内。
- 账户数据库 `bead-lab:{accountId}` 与游客 `bead-lab` 分开。当前项目指针也按作用域保存，写队列绑定实例。账号窗口离线编辑仍保存至对应本机空间。离线冷启动显示游客，联网探测有效会话后出现「恢复账号工作区」。点击后先保存游客草稿，再核验账号并切换工作区。
- 用户可显式把游客草稿复制至个人账号。迁移不删除原记录。本机快照保持已有图纸和色值，服务端写入用版本号防止无提示覆盖。账号缓存的隔离范围是应用入口，不能替代浏览器系统用户权限。
- 色卡缓存使用公开 API，省略 Cookie，持久化最近 16 个发布或退役的版本。只保存规范化的来源、版本、状态与颜色字段。离线使用缓存时标记缓存来源，缺失版本须选择色卡后重新生成，旧项目保留自身图纸色值。实际浏览器离线证据见测试和验收记录。

## 关闭账号、归档与恢复检查

关停事务使用本人会话和密码核验，冻结账户、撤销会话，并撤回本人待审或公开作品。关闭前可下载本人图纸、版本和已登记的私有 PNG。ZIP 范围包含个人资料、项目、版本和私有 PNG。普通后台解冻遇到关闭记录返回 409。恢复验证码发送至关停前已核验的邮箱，有效期 15 分钟。管理员填写验证码和原因后恢复，服务端作废验证码、撤销旧会话并写入审计。

| 对象 | 关闭后状态及恢复验收点 |
|---|---|
| 项目和历史版本 | 保留所有者及项目内容。恢复后新会话使用本人数据，旧会话仍失效。 |
| 原图、掩码、成品及共享引用 | 保留资产文件及外键。历史版本、重绘任务、成品照片的引用阻止孤立图片隔离。预览只列候选与引用规模。 |
| 作品、收藏和二创 | 撤回作品保留审核及溯源记录，原公开链接不再可读。账号恢复后应由作者重新申请发布，已有独立二创不随原项目改写。 |
| 协作成员、房间和操作 | 保留关系及历史格子。所有者关闭期间房间、邀请接收和 WebSocket 不可继续访问，恢复后按成员当前授权读取。 |
| AI 任务和额度流水 | 关闭事务取消排队任务并释放额度。已被工作进程领取或状态未知的任务保留处理和结算依据，未知项由管理员核对。 |
| 订单、会员、库存、举报及审计 | 保留财务和审计引用。已公开或被举报记录可能涉及其他用户。删除方案应先明确这些关系的数据归属、保留与去标识规则。 |

`BEAD_ACCOUNT_RECOVERY_DAYS` 可设为 1–36500 天，留空时默认保留且恢复不受天数限制。管理端清理预览仅按该恢复期限统计超期关闭记录，物理保留期限由项目所有者另行确认。本机孤立资源命令按文件年限和项目、AI 或成品外键判断候选，也可只读预览。[MySQL 部署说明](mysql-platform.md)

## B11 后台指标口径

`GET /api/admin/overview?days=n` 使用 UTC，允许 1–365 天。时间窗口内的三个指标使用包含起止时刻的区间。前端入口为「管理 → 平台概况」。

| 接口字段 | 口径 | 受控数据检查 |
|---|---|---|
| `activeAccounts` | 当前 `active` 账户总数 | 新增 +1，冻结或关闭 −1，普通解冻不新增账户 |
| `savedProjects` | 未移入回收站的服务端项目总数，保留中的关闭账号项目仍计入 | 新建 +1，重复导入不增加，回收 −1，恢复 +1 |
| `pendingPublications` | 仍待审的作品数 | 申请 +1，通过、驳回或撤回 −1 |
| `pendingReports` | 待处理作品举报数 | 第一次举报 +1，重复举报不增加，处理后 −1。社交举报走另一入口 |
| `newAccounts` | 窗口内创建的账号数，含窗口内创建后冻结或关闭的账号 | 用边界内外各一条合成记录，冻结不减 |
| `recentInventoryMovements` | 窗口内实际库存流水条数 | 实际记账递增，幂等重试和失败回滚不增加 |
| `recentPublished` | 窗口内公开且当前仍为上架状态的作品数 | 审核通过递增，撤回或下架后减少，累计发布历史不在其中 |

## 外部服务与本机证据

本次检查只探测执行终端的配置是否非空。真实百炼和 SMTP 的变量在该进程中不可用，未打印值、发出外部邮件或调用收费模型。已有演示实例的模拟环境及历史数据以测试记录为准。

| 范围 | 当前实现与可核对证据 | 真实验收最小条件 |
|---|---|---|
| 百炼 C02/C05 | 后端固定 `qwen-image-edit-plus`，要求匹配的工作空间地址 `BEAD_BAILIAN_ENDPOINT`、密钥 `DASHSCOPE_API_KEY`、`BEAD_AI_ENABLED=1` 与平台实时模式 `BEAD_AI_PLATFORM_LIVE=1`。模拟优先，真实模式要求先评估配置再关闭模拟。任务检查资产所有人、供应商确认、幂等请求号、额度与原图大小。每个任务至多提交一次生成调用，已发请求状态未知时转人工核对。已有本地模拟和真实数据库结算记录。 | 明确地区和模型授权，核对账号可用模型列表及经批准的预算。官方通用文档确认地区端点和请求结构。当前工作空间是否提供本仓库所用模型仍须确认。获准发送一张样例后核对时延和单次结算，再按许可扩大。 |
| 支付 E05 | `PaymentProvider` 仅定义已验证事件契约。`local_mock` 事件从锁定订单生成，应用层检查渠道、订单、金额、币种及合法状态。实际测试采用本地模拟。 | 确定测试渠道、沙箱商户和已授权的回调环境，再对照该渠道官方文档实现真实适配，复验验签、过期、重复事件及异常订单。缺少这些条件时保持模拟环境。 |
| 邮件 F06 | `BEAD_DEVELOPMENT_OUTBOX` 使用本机私有 EML 文件。真实 SMTP 使用 `BEAD_SMTP_HOST`、`BEAD_SMTP_PORT`、`BEAD_SMTP_FROM` 和可选身份认证。开发收件箱优先。真实投递使用系统信任库验证 TLS 证书与主机名，默认隐式 TLS 端口为 465。 | 给定测试 SMTP 和获准的测试邮箱，验证一次送达和一次性找回。开发收件箱投递、真实 SMTP 链路和密码重置后旧会话失效分别记录。 |

官方资料：[百炼图像编辑 API](https://help.aliyun.com/en/model-studio/qwen-image-edit-api) · [百炼模型列表](https://help.aliyun.com/zh/model-studio/models) · [Python 3.12 TLS 默认上下文](https://docs.python.org/3.12/library/ssl.html#ssl.create_default_context)。
