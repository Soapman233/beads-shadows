# 需求与范围
本地单用户辅助设计工具，输入图片并交互选择主体，输出可编辑的有限色数图纸、材料清单与打印分块。
|编号|需求|验收|
|---|---|---|
|R01|多图隔离、TTL与预算|后端合成测试和A→B→A替身|
|R02|EXIF/ICC/alpha规范化|有/无/坏ICC及透明边缘|
|R03|多项目及旧草稿迁移|新建命名复制恢复、旧v2保留|
|R04|掩码画笔|补回擦除撤销，候选失效|
|R05|图纸精修|缩放移动笔画吸色高亮及撤销|
|R06|材料与分块打印|数量一致、每格覆盖一次|
|R07|后台生成与取消|Worker终止与过期结果丢弃|
|R08|配色对照实验|固定资源、网格、K及独立指标|
|R09|可运行交付|类型检查、测试、真实CPU与浏览器|
|R10|毕设材料|设计、实验、论文初稿与演示|
不含云账号、支付、文生图、模型训练和公开多用户服务。学校格式要求待本人提供。
