# 图纸协作

协作房间从当前已保存的项目版本创建。项目所有者可以邀请指定账号加入为查看者或编辑者。邀请三天过期，成员需要接受才有访问权限。所有者可撤销已接受的成员资格，也可撤回未接受的邀请。

房间展示图纸网格与色号。编辑者能画格和保存图纸副本。查看者只能查看。源图、掩码和私人项目界面仍由项目所有者访问。

## 操作与并发

- 每次格子编辑携带请求编号。服务按房间串行分配操作序号，相同内容和编号重复提交时返回原操作。
- WebSocket 建立连接后发送完整网格，并持续发送新操作、成员和选区光标。重新连接可以从快照恢复。服务每轮重新验证会话、项目状态和成员资格。
- 撤销是新操作。只有被撤销笔画属于当前用户，且所有涉及格子当前仍是该笔画的结果时，才能撤销。受他人后续编辑的格子会保留。
- 每个项目当前只有一个编辑房间。拍板采用时，所有者提交看到的操作序号。服务核对项目基础版本和房间序号，再创建一个新的私人项目版本。
- 普通项目保存、历史版本恢复与回收站操作会在活跃房间返回冲突。先保存协作版本、明确结束房间，或通过结构更新流程保存尺寸、色卡或生成结果。
- 结构更新成功后，成员可以从项目详情的 `archivedRoomId` 打开最近一间已结束房间。拥有编辑权限的成员可以另存旧网格。
- 所有者账号冻结或关闭时，项目和邀请从协作列表隐藏。房间及操作记录保留，现有连接会在下一轮检查时结束。

## 结构更新接口

1. 所有者向 `POST /api/collab/rooms/{room_id}/structure/lease` 提交 `expectedRevision`、`expectedSequence` 和一次操作专用的 `requestId`。成功返回 `leaseId`、`expiresAt`、`baseRevision` 和 `sequence`。同一会话重试相同请求可恢复租约，其他操作需要等当前租约结束。租约约 75 秒后自动到期。
2. 使用 `POST /api/collab/rooms/{room_id}/structure/commit` 提交新版图纸，复用普通项目保存的 `name`、`project`、`source_id`、`mask_id`、`expected_revision` 字段，并附 `leaseId`、`expectedSequence`。服务端在同一事务内验证租约和项目状态、创建新版本并结束旧房间。重试相同提交会拿到原保存结果。
3. 放弃时可用 `DELETE /api/collab/rooms/{room_id}/structure/lease/{lease_id}` 释放租约。租期内服务会拒绝笔画、撤销、普通协作提交和关闭房间。房间读接口及 WebSocket 仅显示 `structureLockedUntil`，租约 ID 仅在获取结果中返回给所有者。

## 运行与验证

安装后端依赖并执行 `alembic upgrade head`。生产 WebSocket 使用同源 `/api/collab/ws/{room_id}`，开发代理可以转发到 `/collab/ws/{room_id}`。连接必须来自站点自身或 `BEAD_WEB_ORIGIN` 配置的开发入口，并携带有效登录 Cookie。

定向验证使用隔离 MySQL 8.4。已验证邀请、查看权限、操作重放、顺序、撤销冲突、安全副本、成员撤销、提交和重新建房。操作及快照持久保存。在线成员与光标保存在服务进程内，适用于当前的单进程部署方式。

结构更新已通过独立 MySQL HTTP 验收，覆盖普通保存和恢复保护、同会话重试、跨会话拒绝、竞争、到期和旧房间保留。服务层另验证了主动取消以及所有者冻结后的协作访问限制。
