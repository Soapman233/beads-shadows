# P2 可控实验记录

日期：2026-11-16。输入12份：3张真实照片（NASA public domain、CC0）和9份原创合成边界/平涂/渐变样例；合成样例不冒充真实照片。未计算文件哈希。

## 方法和来源

固定每份规范化source、有效alpha mask、crop、64格宽、K16和MARD社区220色版本；不重分割。A组同mean代表色比较RGB频次、普通Oklab、色相权重4与两步单色交换候选。全色库仅诊断。所有DE00采用独立sRGB→线性RGB→XYZ D65→CIELAB→CIEDE2000，参数kL=kC=kH=1。均值为有效格等权，P95为有效格颜色误差分位数，不是少量运行时间的P95。

公式及已知对：[Sharma/Wu/Dalal作者页面](https://hajim.rochester.edu/ece/sites/gsharma/ciede2000/)、[2005论文](https://hajim.rochester.edu/ece/sites/gsharma/ciede2000/ciede2000noteCRNA.pdf)、[作者测试数据](https://hajim.rochester.edu/ece/sites/gsharma/ciede2000/dataNprograms/ciede2000testdata.txt)。独立实现没有复制作者MATLAB代码；8个已知对覆盖蓝色交叉项符号、零色度、色相跨界/近180度，容差0.0001；黑白sRGB转换一并通过。

真实图来源沿用mvp/samples/SOURCES.md：scikit-image v0.25.2 astronaut NASA、公有领域；chelsea CC0 Stefan van der Walt；coffee CC0 Rachel Michetti。原图既有资源仅读取，不重新下载。输入清单在experiments/generated/manifest.json。所有实验生成数据和图在gitignored目录，用户角色图未复制或上传。

## B组：相同原像素参考的取样对照
