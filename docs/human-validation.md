## 可复现的32×32实物材料包

已提供 `experiments/prepare-human-kit.ts`，复用既有原创几何人物输入 `experiments/generated/synthetic-3.json`，以默认 hue4、32格、K8生成，不用用户私图。若尚无实验输入，先按实验文档执行 `tests/prepare_experiments.py`。仓库根目录运行：

```powershell
.\frontend\node_modules\.bin\tsx.cmd experiments/prepare-human-kit.ts
```

输出位于忽略目录 `experiments/generated/human-kit/`：

- `project-32x32.json`：通过项目校验的纯图纸v2项目，可在应用导入；导入应创建独立项目。
- `materials-10percent.csv`：按同一图纸重新统计的实际量与加10%逐色向上取整备料量。
- `pattern.svg`、`print.html`：32×32图纸、行列号、数字符号与图例；空格以×表示，白色豆同样标数字，黑白打印可区分；HTML按钮可调用浏览器打印/保存PDF。
- `record-template.md`：实物批次、钉距、耗时、缺豆/错色与光源记录空表。

本轮实际生成结果为1024颗、8色：H2 490、H9 22、A23 219、M7 4、M15 2、H5 1、C23 44、C24 242。它是材料准备结果，实体制作、实物色差和轻薄本验证仍待本人完成。少量色用于细节，不自动删去；采购前先核对手头色号与批次。

打印建议使用A4，检查完整图例和右下末格后再施工。SVG固定为160mm显示宽度，是按格阅读的施工图，不是豆板1:1定位模板；不要将图纸显示尺寸当作成品尺寸。按钉距2.6mm估算32格跨度约8.3cm，具体以实物豆板为准。

2026-11-25 重新生成了上述包。脚本校验了图纸与 SVG 的结构、CSV 八种色号的逐色数量，以及打印页的 50 mm 标尺。按 100% 缩放打印后，先量标尺、再填写实物记录。样张尺寸的实物测量仍待现场完成。

## 桌面 CPU 复现实验

使用同一份原创合成输入测量图纸生成。若缺输入，先按实验文档准备。命令在仓库根目录运行。

```powershell
.\frontend\node_modules\.bin\tsx.cmd experiments/run-cpu-benchmark.ts
```

2026-11-25 在 Windows x64、Core Ultra 7 265K、31.3 GiB 内存及 Node 24.14.0 的台式机测得。输入 128×128，图纸 64×64，K16 上限，输出 4096 颗、12 色。进程到首轮前的准备为 574 ms，首次生成 26.84 ms，三次热跑 14.96、12.48、12.61 ms。进程峰值 RSS 约 94 MiB。该值含 Node 运行时。耗时范围为本地算法入口，完整上传、浏览器交互及轻薄本留待设备测试。
