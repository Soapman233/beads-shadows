# 同条件 K-Means＋Lab 基线

复用现有18份公开许可或原创输入，包括9张公开许可/公有领域照片和9份合成样例。两种方法固定源图、有效 alpha 掩码、裁剪、64格宽、mean 采样、MARD220 色卡及最多16色。未上传用户图片，未主动核验文件哈希。

基线对有效格代表色做 CIELAB 欧氏距离的 Lloyd K-Means。以首个有效格为起点，按最远点选择初始中心，顺序确定时结果可复现。迭代50次或中心移动足够小时停止。聚类中心匹配到同一真实色卡，合并重复色号，随后每格在这个子集中匹配最近 Lab 颜色。对照为当前 Oklab 色相加权方法。两者均按独立 CIEDE2000 评估，逐格断言不改变掩码和网格，每个色号均属固定物料库，且实际用色不超过16。

按图等权平均的 DE00 均值分别为 5.121 与 5.646。K-Means 在12张图误差较低，Oklab在5张图较低，另1张相等。两者实际用色相同的6张图里，K-Means两张较低，Oklab三张较低，另1张相等。部分照片的 P95 优势与均值结论不同，例如 astronaut 和 coffee。平均用色分别为7.78与10.78。两者固定色数上限，实际用色可不同。结果不支持宣称 Oklab 普遍更好，也不直接推出所有产品场景应更换默认算法。小样本、单一色卡、单一初始化和色数上限限制了外推。

本机 Node v24.14.0 单次运行按图平均约 6.97ms 与 55.23ms，含采样，不含导入解码、分割和评价。运行顺序固定，未做去偏、多次预热或轻薄本测量。

在仓库根目录用现有 Python 环境执行 `tests/prepare_experiments.py`（已有公共样例可复用），再执行 `frontend/node_modules/.bin/tsx.cmd experiments/run-kmeans-lab.ts`。逐图源来源、实际用色、耗时与误差写入忽略的 `experiments/generated/kmeans-lab-results.json`。来源见 `examples/dataset/SOURCES.md`，独立测量公式见 `docs/experiments.md`。
